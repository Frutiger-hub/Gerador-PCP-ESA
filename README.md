# Gerador PCP ESA

Aplicação desktop para leitura, análise e geração de relatórios de PCP a partir de relatórios PDF da ESA.

## Recursos
- Leitura de PDFs com múltiplas fases
- Relatórios completo e resumido
- Consultas PCP e filtros por O.S.
- Gestão de atrasos
- Histórico e observações
- Interface desktop em português

Versão de desenvolvimento: 9.8.7
